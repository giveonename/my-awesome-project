- [2026-10-07] **模板残留全部删除**（frontend/ Web 端、k8s/、nginx/、dev+prod compose、release-please 发版套件）— 只保留小程序+后端；LICENSE 因 MIT 署名义务保留
- [2026-10-07] **主题方向 A 全量换色**：深墨绿 #2D6A4F + 奶油白 #FAF7F2，阴影转暖棕黑 — 让 UI 退为"画框"衬托衣物照片；否掉了纯换主色（只完成一半）与高饱和方案
- [2026-10-07] **ootd 页面保留**并接入首页"今日穿搭"卡片 — 功能完整（真实天气+7天预报）且答辩演示有价值；否掉了删除方案（discover/evaluation 已删）
- [2026-10-09] **文本模型 MiMo → DeepSeek**（模型 ID `deepseek-flash`）— MiMo 余额耗尽；DeepSeek 原生多模态，API 只认全小写 ID（公告营销名不可用）
- [2026-10-10] **试衣模型 → qwen-image-3.0**（aitryon 家族 2026-10-10 官方下线）— 同步 API + 本地图 Base64 输入，**试衣不再依赖 OSS**；整套 outfit 直传参考图不拆分
- [2026-10-10] **穿搭照不拆分**（上传即 1 条 outfit 记录进试衣间）— 简化流程且符合产品直觉；只有平铺多件才走分割拆件
- [2026-10-10] **提示词属性只写来自真实衣物元数据的内容**，"衣长比例交由商品图" — 实验证实：错误的长度声明会主动扭曲商品（正确声明能治好下摆偏差）
- [2026-10-12] **搭配池 P1 架构**：预生成池 + arq worker + Redis 记状态 — **刻意不加数据库表**（迁移图损坏，避免新 revision）；试穿生成从进程内任务迁 worker（重启不丢）
- [2026-10-12] **完成通知走应用内**（首页社区横幅 🔔 插播、点击跳转+已读）— 小程序无系统推送能力（除非订阅消息模板，需用户每次授权）；横幅"插播优先"不永久霸占社区位
- [2026-10-12] **搭配池成本帽**：显示 2 套/池子目标 4 套/每日补货预算 2 批（约 ¥1.44/天上限）— 防止反复打开反复烧钱；关闸=调小配置
- [2026-10-12] **头像昵称走微信官方能力**（chooseAvatar + type=nickname，2022 政策唯一合规路径）；头像 DB 存相对路径、响应时实时签名（防签名过期头像消失）
- [2026-10-11] **OSS 不再强依赖**：浏览/识别/试衣/天气背景全面本地化 — 续费与否只剩"历史数据公网链接"意义，用户可从缓决定
